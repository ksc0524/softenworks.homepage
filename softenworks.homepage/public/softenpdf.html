01

정확한 차이 분석

페이지의 텍스트, 이미지와 시각 요소를 분석하여 추가·삭제·변경된 영역을 식별합니다.

02

직관적인 결과 확인

원본과 변경본을 나란히 보거나 중첩하여 결과를 조회하고, 차이가 발생한 위치를 빠르게 탐색합니다.

03

비교 차이점 요약

텍스트 및 이미지의 차이점에 대해 Before / After 목록 형식으로 비교 결과 요약 정보를 제공합니다.

04

기존 시스템 연계

PLM/ALM, CMS/DMS, CDM, 업무 프로세스 등 레거시 업무 시스템과 연계하여 비교/검증을 자동화할 수 있습니다.

FEATURES

주요 기능

비교 대상 등록부터 결과 검토와 시스템 연계까지, 실제 문서 검증 업무에 필요한 흐름을 하나로 연결합니다.

01

IMAGE COMPARISON

PDF 도면·이미지 비교

  • 두 PDF도면/이미지를 겹쳐서 차이를 비교. 각종 편의 기능으로 두 도면 간 변화 추이 확인
  • 두 도면 간 다른 부분(Diff)의 전체 개수 제공 및 diff 간 이동 기능 제공
  • 언어전환, URL공유, 전체 맵, 이미지 타일화, 비교 정보 등 툴 버튼 제공
  • 정확히 다른 부분 Diff 및 영역화 Diff 표시/숨기기/투명도 조절 기능 제공(도면 이미지 내 해당 위치에 표시)
  • 도면 이동/확대/축소/오토줌 및 이미지맵 제공
  • Diff 썸네일 리스트 Summary 제공 및 해당 부분으로 이동
02

OPTIONS FOR IMAGE COMPARISON

다양한 도면, 다양한 비교 옵션

  • 비교 시 미세한 차이 또는 개체 간 간섭 등에 의한 노이즈를 최소화 할 수 있는 각종 옵션 제공
  • Diff 표시 방식을 변경할 수 있는 각종 옵션 제공
  • 회전, 사이즈, 도면이동 자동 조정 옵션
  • 워터마크 제외 옵션
  • 재단 영역 자동/수동 조정 옵션
03

TEXT COMPARISON

요구사항, 스펙 등 문서 간 텍스트 비교

  • 오른쪽 문서 대비 삭제된 부분 표시
  • 왼쪽 문서 대비 추가된 부분 표시
  • 두 문서 간 다른 부분(Diff)을 북마크 형식으로 제공하여 클릭 시 해당 위치로 스크롤
  • 언어 전환, 스크롤 동기화 등 기능 버튼 제공
  • 상호 다른 부분 Diff Summary 제공. 클릭 시 이동
04

OPTIONS FOR TEXT COMPARISON

다양한 텍스트 특성, 다양한 비교 옵션

  • 텍스트 비교 알고리즘 옵션
  • 공백 종류 관련 비교 옵션
  • 재단 영역 자동/수동 조정 옵션
  • 재단 외 영역 비교 제외 옵션
05

FOLDER COMPARISON

서버 폴더 간 비교

  • 서버의 두 폴더 내 파일 간 매칭 및 비동기식 자동 비교
  • 서버의 폴더 및 파일 관리 기능 제공
  • 폴더 비교 진행 현황 제공
  • 폴더 비교 결과 이력 관리
  • 폴더 간 파일 비교 결과 Summary 제공
06

EXTENDABLE

확장성, 다양성, 유연성

  • 어플리케이션 기반의 다양한 설정 제공
  • 비교 영역 분리 및 접근 권한 설정 제공
  • 비교 영역 별로 분리된 다양한 설정 제공
  • 국제화/로컬화 언어 확장성 지원
  • 시스템 확장을 위한 플러그인 개발 환경 지원
  • RESTful API 제공
  • SSO(Single Sign On) 지원

REFERENCES

구축 사례

문서와 도면을 정확하게 검증해야 하는 교육, 조선과 제조 현장의 업무에 SoftenPDF를 적용했습니다.

03

TEXTBOOK

공공 분야 교과서 자동 비교/검증

  • 교과서 개정 시 수정 및 보완 사항을 자동 검증
  • 텍스트 기반 비교, 이미지 기반 비교 모두 활용
  • 수백 페이지 대용량 문서 비교
  • 폴더 간 비동기식 대량 파일 비교
  • 타 시스템과 통합 인증 구성
  • REST API를 활용하여 비교 결과 데이터 전송
  • 다양한 텍스트 관련 옵션 추가
02

SHIPBUILDING

조선 분야 도면 자동화 비교 시스템

  • 개인 별 로컬 파일 도면/문서 비교
  • 수백 페이지 대용량 도면 파일 비교
  • 시리즈선 설계 시스템과 비교 기능 연계 구성
  • RESTful API를 활용하여 대량 자동화 비교
  • 시리즈선 자동화 비교와 일반 비교의 영역을 분리
  • 비교 영역 지정 및 제외 옵션 기능 추가
01

MANUFACTURING

제조 분야 도면 자동화 비교 시스템

  • 설정된 주기에 자동비교 Service 호출
  • 자동 비교할 대상을 추출하여 해당 버전 및 이전 버전의 팀센터 다운로드 URL 확인
  • 두 도면의 파일을 NAS에 다운로드(회로 도면의 경우 NAS에 직접 접근)
  • 다운로드한 파일의 위치 정보를 포함하여, Soften PDF의 비교 요청 RESTful API 호출
  • 두 도면에 대해 비교하고 그 결과 파일을 NAS에 저장
  • 비교 결과 ID를 반환
  • 비교 결과 메타정보를 PLM DB에 저장
  • 도면 조회 화면에 Soften PDF 비교결과 조회 화면으로의 링크를 제공
