OVERVIEW

SIEMENS Polarion ALM의 프로젝트를 편리한 K-Gantt 로 관리하세요.

01직관적인 일정관리

드래그 앤 드롭으로 작업 일정을 손쉽게 조정하고, 프로젝트의 전체 흐름을 한눈에 파악할 수 있습니다.

02편리한 간트 편집 도구

작업 추가·삭제·복사부터 확대·축소, 실행 취소까지 다양한 도구로 일정 편집을 빠르게 수행합니다.

03WBS 및 의존관계 관리

계층적인 WBS와 작업 간 선후행 관계를 시각화하여 복잡한 프로젝트 구조와 일정 영향을 명확하게 관리합니다.

04정확한 진척도 관리

계획·실적·잔여 작업을 기준으로 진척도를 확인하고, 일정 지연과 주요 변경 사항을 빠르게 파악합니다.

01

체계적인 자원 현황 파악

담당자별 작업 일정과 투입 현황을 확인하여 업무 집중과 자원 충돌을 줄이고 효율적인 배분을 지원합니다.

02

유연한 플러그인 옵션

프로젝트 특성과 업무 방식에 맞게 화면 구성, 표시 항목, 필터와 주요 동작을 다양하게 설정할 수 있습니다.

03

Polarion 완벽 연계

Polarion의 Work Item, Plan 및 프로젝트 데이터를 기반으로 별도의 데이터 이관 없이 일정을 관리합니다.

04

신속한 고객 요구 대응

실제 업무에서 필요한 기능을 지속적으로 반영하고, 고객 환경에 최적화된 확장과 기술 지원을 제공합니다.

FEATURES

주요 기능

Polarion의 다양한 work item 과 복잡한 상관 관계를 간트 차트로 표현하고 편리하게 편집하세요.

01

OVERVIEW

Polarion ALM에 최적화 된 Gantt Chart Editor/Viewer

  • 다양하고 복잡한 Work Item 상·하위 구조 지원
  • Drag & Drop 으로 일정 변경 및 스크롤 이동
  • FS / SS / SF / FF 선·후행 상관 관계 지원
  • Plan 과 연관된 WBS 조회 기능
  • 다양한 툴 버튼 및 확장 기능 제공
  • Work Item 기반 진행률 계산
  • 다양한 Widget Parameter 로 구성 변경
  • 신속한 고객 요구사항 대응
02

TOOLS & EXTENSIONS

다양한 도구 기능 및 확장 도구

  • 기본 편집 도구: Save, Redo, Undo, Reload
  • Scheduling 도구: Auto scheduling, Critical Path
  • Expand, Collapse, 전체 화면
  • Scale 조절 기능: 확대, 축소, 전체 일정 보기
  • Today Flag
  • 확장 도구:
    • Resource View
    • Baseline Flag
    • 베이스라인 시점의 일정 조회
    • 베이스라인 시점과 일정 비교
03

WIDGET PARAMETERS

Gantt 차트를 다양하게 구성해 주는 Widget Parameters

  • Gantt 차트를 다양한 스타일로 표현하기 위한 파라미터
  • Work Item 구조를 구성하기 위한 Dataset 파라미터
  • Task 데이터와 Work Item 필드를 매핑하는 파라미터
  • 진행률 계산 방식 선택 파라미터
  • Task의 종류가 지정되는 방식을 선택하는 파라미터
  • Polarion Calendar 적용
  • FS/SS/FF/SF 를 Link Role 과 매핑하는 파라미터
  • Read Only Gantt 및 Grid 내 인라인 편집 옵션
  • Grid 에 Work Item 필드를 추가하는 파라미터
  • Resource View 및 Time Spent 소스 지정 파라미터
  • 확장 Tool 추가 파라미터
  • 커스텀 Script 및 Styles
04

RESOURCE VIEW

Work Item 에 지정된 담당자 별로 할당된 공수를 다양한 방식으로 표현

  • Widget Parameter 로 Resource View 확장 도구 추가
  • 담당자 별 전체 할당된 공수 파악
  • 일/주/월간 할당된 공수 파악
  • 선택한 담당자가 할당된 Task 만 필터링하는 기능
  • 8시간 기준 초과 할당된 경우 스타일 구분 표시
  • 다양한 할당량 계산 방식 지원:
    • 정확한 일자 또는 균등 분할 옵션
    • Initial Estimate: 계획 공수 기반으로 계산
    • Remaining Estimate + Time Spent: 현 시점 총 공수 기반으로 계산
    • Time Spent: 사용한 시간(Time Spent 만으로 계산
    • Task Count: 할당된 Task 개수
