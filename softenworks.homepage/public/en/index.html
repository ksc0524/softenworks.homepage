PDF

SoftenPDF

A web-based solution for comparing PDF documents, engineering drawings, and images. Our proprietary algorithms detect changes quickly and accurately and present clear, actionable summaries.

Learn More
Gantt

SoftenGANTT

A Gantt widget for planning, editing, and managing project WBS structures and schedules directly from Polarion Work Items.

Learn More
Grid

SoftenGRID

A widget extension that displays Siemens Polarion ALM Work Items in configurable, information-rich grids.

  • Configure a wide range of grid options through widget parameters
  • Apply automated row-span and column-span formatting
  • Customize most features to fit project requirements
