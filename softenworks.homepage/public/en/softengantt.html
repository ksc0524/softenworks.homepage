FEATURES

Core Features

Visualize diverse Polarion Work Items and complex relationships in a Gantt chart, then edit schedules with ease.

01

OVERVIEW

A Gantt Editor and Viewer Purpose-Built for Polarion ALM

  • Support diverse and deeply nested Work Item hierarchies.
  • Change dates and navigate the schedule with drag-and-drop interaction.
  • Model finish-to-start, start-to-start, finish-to-finish, and start-to-finish dependencies.
  • View WBS structures associated with Polarion Plans.
  • Use a broad set of editing tools and optional extensions.
  • Calculate progress from Work Item data.
  • Configure the experience through flexible Widget Parameters.
  • Extend capabilities quickly in response to customer requirements.
02

TOOLS & EXTENSIONS

Powerful Editing Tools and Extensions

  • Core editing: Save, Undo, Redo, and Reload
  • Scheduling: Auto Scheduling and Critical Path
  • Expand, Collapse, and full-screen views
  • Timeline scale controls: zoom in, zoom out, and fit the entire schedule
  • Today marker
  • Optional extensions:
    • Resource View
    • Baseline marker
    • View the schedule as of a selected baseline
    • Compare the current schedule with its baseline
03

WIDGET PARAMETERS

Widget Parameters for Precise Configuration

  • Style the Gantt chart for different reporting and planning contexts.
  • Shape Work Item hierarchies with dataset parameters.
  • Map task data to Polarion Work Item fields.
  • Select the progress calculation method.
  • Control how task types are determined.
  • Apply Polarion project calendars.
  • Map FS, SS, FF, and SF dependencies to Polarion Link Roles.
  • Enable read-only Gantt mode or inline editing in the grid.
  • Add selected Work Item fields to the grid.
  • Configure Resource View and the Time Spent source.
  • Add optional extension tools.
  • Apply custom scripts and styles.
04

RESOURCE VIEW

Visualize Assigned Effort by Work Item Assignee

  • Add the Resource View extension through Widget Parameters.
  • Review total assigned effort for each assignee.
  • Analyze assigned effort by day, week, or month.
  • Filter the Gantt chart to tasks assigned to selected people.
  • Highlight daily allocations that exceed an eight-hour threshold.
  • Choose from multiple allocation methods:
    • Allocate effort to exact dates or distribute it evenly
    • Initial Estimate: calculate from planned effort
    • Remaining Estimate + Time Spent: calculate total current effort
    • Time Spent: calculate from recorded time only
    • Task Count: count assigned tasks
