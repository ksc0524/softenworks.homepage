FEATURES

Core Features

Connect the entire document verification workflow—from file registration and comparison to result review and enterprise integration.

01

IMAGE COMPARISON

Compare PDF Drawings and Images

  • Overlay two PDF drawings or images to inspect changes and trace design revisions with ease.
  • View the total number of detected differences and move directly from one difference to the next.
  • Use language switching, shareable URLs, overview maps, image tiling, and detailed comparison information.
  • Show, hide, or adjust the opacity of precise and region-based difference overlays at their exact locations.
  • Pan, zoom, fit to view, and navigate with an image map.
  • Review a thumbnail-based difference summary and jump to any result with one click.
02

OPTIONS FOR IMAGE COMPARISON

Flexible Options for Every Drawing

  • Fine-tune comparison settings to suppress noise caused by minor variations or overlapping objects.
  • Choose from multiple difference visualization modes.
  • Automatically align rotation, scale, and drawing position.
  • Exclude watermarks from comparison.
  • Set the crop area automatically or manually.
03

TEXT COMPARISON

Compare Text Across Requirements and Specifications

  • Highlight text removed from the revised document.
  • Highlight text added to the revised document.
  • List differences as bookmarks and scroll directly to the selected location.
  • Use language switching, synchronized scrolling, and other review controls.
  • Review a complete difference summary with one-click navigation.
04

OPTIONS FOR TEXT COMPARISON

Comparison Options for Different Text Structures

  • Select the text comparison algorithm that fits your documents.
  • Control how spaces and whitespace differences are handled.
  • Set the crop area automatically or manually.
  • Exclude content outside the defined crop area.
05

FOLDER COMPARISON

Compare Server Folders at Scale

  • Match files across two server folders and compare them asynchronously.
  • Manage server-side folders and files.
  • Monitor folder comparison progress.
  • Retain a history of folder comparison results.
  • Review a consolidated summary of file-level results.
06

EXTENDABLE

Flexible by Design, Ready to Extend

  • Configure a broad range of application settings.
  • Separate comparison workspaces and control access permissions.
  • Apply independent settings to each comparison workspace.
  • Extend internationalization and localization support.
  • Use the plug-in development environment for system extensions.
  • Integrate through RESTful APIs.
  • Support single sign-on (SSO).

MANUFACTURING

Automated Drawing Comparison for Manufacturing

  • Invoke the automated comparison service at scheduled intervals.
  • Identify drawing pairs and retrieve download URLs for current and previous revisions from Teamcenter.
  • Download both drawings to NAS storage, or access circuit drawings directly on the NAS.
  • Call the SoftenPDF REST API with the downloaded file locations.
  • Compare both drawings and store the output files on the NAS.
  • Return a unique comparison result ID.
  • Store comparison metadata in the PLM database.
  • Link the drawing viewer directly to the corresponding SoftenPDF results.
